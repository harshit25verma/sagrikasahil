# Sagrika & Sahil — A Journey to Forever

A mobile-first interactive wedding invitation (Vite + vanilla JS + Canvas + Web Audio). No backend, no accounts, no RSVP.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173 (also reachable from your phone on the same Wi-Fi)
```

## Build & preview
```bash
SITE_URL=https://your-real-domain.com npm run build   # writes ./dist
npm run preview
```
`SITE_URL` replaces the placeholder in the Open Graph / Twitter tags. If you skip it, the tags keep
`https://YOUR-PUBLIC-DOMAIN` — **you must set the real domain before sharing**, or WhatsApp will not find the preview image.

## Deploy (any static HTTPS host)
Upload the contents of `dist/` (or connect the repo) to Netlify, Vercel, Cloudflare Pages, GitHub Pages, etc.
Build command: `npm run build` · Output directory: `dist` · Environment variable: `SITE_URL=https://your-domain`.
The build uses relative paths, so it also works from a sub-folder. After deploying, open
`https://your-domain/assets/og-image.png` to confirm it loads. WhatsApp caches previews; to refresh one use
Facebook's Sharing Debugger or add `?v=2` to the link.

## Checks
```bash
npm run check            # asset manifest, broken paths, OG image is a real 1200x630 PNG, spelling/copy, no RSVP
node scripts/sim-game.mjs  # headless run of the whole game engine (finishes at 25s, forgiving collisions)
```

## Editing
- Wedding text: `index.html` (all live HTML text). Venue/share text: `src/navigation.js`.
- Game tuning (duration, speed, obstacles, jump): top of `src/game.js`.
- Illustrations are generated by `scripts/build-assets.mjs` (`npm run assets`) so the four characters are identical on every screen.

## Notes
- Sound starts muted; the toggle (top-right) creates the audio context on tap. All sounds are synthesised — no audio files.
- Nothing is stored (no localStorage/sessionStorage); refreshing restarts from the first screen.
- The guests' reference photos are not part of the project or the public site.
- After the invitation there is a small "Continue ✦" link that leads to the closing screen.
